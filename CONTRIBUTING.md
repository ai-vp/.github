# Contributing to AI VP

Welcome to contribute to AI VP!

## What can you contribute
- Fix typo, broken links in documents
- Add new prompt templates
- Add AI agent tutorials and knowledge content
- VuePress / VitePress theme & site demos

## Contribution workflow
1. Fork the target repository
2. Create your feature branch
3. Commit your changes
4. Open a Pull Request

## Rules
- Keep content concise and clear
- Follow markdown format
- No commercial, illegal or irrelevant content
